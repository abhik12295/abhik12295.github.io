# Abhishek Kumar — Modern Portfolio

A fast, responsive static portfolio designed for GitHub Pages. The site highlights enterprise AI and logistics experience, doctoral education, verified research publications, and selected open-source projects.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

After GitHub Pages is enabled with **GitHub Actions** as the publishing source, the included workflow deploys every update to `main` automatically. The expected URL is:

`https://abhik12295.github.io/portfolio_streamlit/`
